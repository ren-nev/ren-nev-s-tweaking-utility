How the switches work
Gray means the tweak is off. Green means Windows reports it as applied. Clicking a switch runs the matching apply or restore command, then the utility checks Windows again before it updates the state. LOW / MEDIUM / HIGH describes performance usefulness—not danger. In v17, HIGH means the effect can be large when the condition in the description actually applies; it is not a guaranteed FPS increase. Six one-click settings are marked HIGH-conditional, while most service/privacy/task tweaks remain LOW because they usually do very little for game FPS.
Security/boot-protection disables, mass network resets, Windows Update shutdowns, and other risky “optimizer” tricks are intentionally excluded. The utility should improve or simplify your setup without pretending that weakening Windows is a performance feature.

Recommended // Start Here
A simple guide to the changes that are actually worth checking first. HIGH now means high conditional potential, not a guaranteed win; the Fortnite/Roblox benchmark lab can prove whether a change helped your own PC.
Impact colors are only a guide: HIGH can matter a lot on the right PC, MEDIUM is more moderate, and LOW is usually small or situational. The benchmark is more important than the label.
✦
Run Smart Scan first
Smart Scan checks your hardware and current Windows state before it recommends anything. It avoids applying the same preset to every PC.
↶
Create a restore point
Do this before a batch of changes. The utility also keeps per-tweak restore commands, but a Windows restore point gives you an extra recovery option.
◫
Check startup apps
Too many programs starting with Windows can matter more than disabling tiny services. Remove or disable startup software you do not actually need.
◆
Gaming basics
Game Mode is a sensible default. Game capture is only worth disabling if you do not use it. HAGS should be A/B tested because results vary by GPU, driver and game.
⌁
Power plans are not magic
Modern CPUs scale dynamically. Balanced is a strong default for most systems; High Performance can be tested while plugged in, but more heat/power does not guarantee more FPS.
↔
Avoid random “ping tweaks”
Windows network offloads and RSS are often beneficial. The utility does not mass-disable TCP/offload features or promise lower ping from placebo registry values.
▰
Keep storage healthy
Keep free space available and leave Windows drive optimization enabled. On SSD/NVMe systems, TRIM should normally stay enabled.
↻
Updates and drivers matter
Windows updates and current GPU/chipset drivers can contain real stability and performance fixes. Update before blaming the OS scheduler or registry.
▣
Verify display settings
A high-refresh monitor only helps if Windows is actually using the intended refresh rate. Also make sure demanding games use the correct GPU on multi-GPU systems.
✓
Benchmark changes
Use the new Fortnite/Roblox in-game BEFORE/AFTER lab for real frame timing, plus the synthetic lab for Windows responsiveness. Keep graphics settings and routes the same; tiny differences can be normal run-to-run noise.
!
Security is not an FPS tweak
DEP, integrity checks, VBS/Memory Integrity, TPM/ELAM and similar protections are intentionally not treated as normal one-click performance tweaks.
i
What the impact labels mean
LOW = small/situational. MEDIUM = meaningful but usually limited or inconsistent. HIGH = potentially large when the card’s stated condition really applies. A HIGH label is never a promise: prove it with the benchmark lab.

Debloat // Background Load Control
Closes optional apps you choose before gaming. It leaves important Windows, driver, audio, network and security processes alone.
You stay in control: Ren Nev only closes the apps you select. Things like Discord, music and cloud sync stay optional because some people want them open while gaming.
Auto Session Debloat
When enabled, every Launch with Boost runs the selected cleanup once before the game starts. It does not constantly kill apps you reopen later.

Performance
Small Windows changes for background load and how fast the desktop feels. Tweaks are grouped below so you can find what you need.
Gaming
Windows settings that can affect games or input. Some help only on certain PCs, so use the benchmark when a card says results can vary.
Privacy

Network // Health Lab
Checks your real active connection, router ping, internet ping, DNS and Wi-Fi signal. Use it to find where a connection problem actually starts.

Supported Windows network settings
These remain separate from the health check. Apply only when the description matches your setup, and use actual game latency/jitter to judge whether a change helped.
Storage
Storage health settings. Ren Nev only recommends SSD-specific options when it actually sees an SSD or NVMe drive.
Services
Optional Windows features that run in the background. Only disable a section when you do not use the feature it controls.
Scheduled Tasks
Small jobs Windows runs by itself from time to time. These are grouped by what they do, and most only make a tiny performance difference.
Power
Controls how aggressively Windows saves power. Faster modes can use more electricity and create more heat, so only keep them when testing shows a benefit.
Maintenance
One-shot repair and network actions rather than persistent switches.
System Tools
Shortcuts to built-in Windows tools. These do not silently change settings.
Excluded / Review
These were intentionally not made into normal toggles because they are risky, too destructive, unreliable, or counterproductive as general performance tweaks.
